A 30-day plan an AI agent can carry out itself to turn $100 into the most money: sell AI product-photo packs to Shopify sellers. Day 1, list a $29 "10 AI product photos, 24h delivery" gig on Fiverr and email 100 Shopify stores from BuiltWith's free list; days 2-30, fill each order in 24 hours, collect reviews to climb Fiverr search, and reinvest every dollar into more outreach. Target: 20 orders = $580, spending $0 before the first sale.

`main.py` (Python 3.13, stdlib only) writes the plan text to `/output/entry.txt`. It is deterministic: two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
